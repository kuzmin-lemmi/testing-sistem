# План проверки в школе

Цель: убедиться, что система работает в настоящем кабинете — по сети, на компьютерах учеников,
в браузере и в программе ученика (запертый экран). Время в школе: около 1,5 часа. Подготовка дома: около 30 минут.

Обозначения: **У** — компьютер учителя, **У1** — ученик в браузере, **У2** — ученик в программе ученика.
Нужно минимум 3 компьютера; для последней проверки (весь класс) — все компьютеры кабинета.

---

## Этап 1. Дома: собрать флешку

### 1.1. Собрать систему учителя в EXE

На своём компьютере, в папке `testing-sistem`:

1. Дважды щёлкнуть `BUILD_EXE.bat` (нужен интернет: поставит PyInstaller).
2. Дождаться «Готово: dist\Тестирование\Тестирование.exe».
3. Запустить `dist\Тестирование\Тестирование.exe` — должна открыться главная страница. Остановить систему кнопкой
   «Остановить систему».

### 1.2. Собрать программу ученика

В папке `testing-sistem\student_app`: `cargo build --release` (или взять готовый `target\release\student_app.exe`).

### 1.3. Пробный вариант

**Готов:** [`docs/Проверка в школе.variant`](Проверка%20в%20школе.variant) (ответы: 1024; 6 и 36; 1, 2, 3, 6; 1761; 8 —
посчитаны кодом, вариант проверен загрузкой в систему: 5 из 5). Собирает его `scripts/make_check_variant.py`.
Состав:

| № | Задание | Зачем |
|---|---|---|
| 1 | обычный ответ (число) | основной сценарий |
| 2 | два поля ответа | несколько полей |
| 3 | «несколько строк» | ответ как в № 25/27 |
| 4 | ответ + **файл к заданию `.xlsx`** | скачать файл и открыть в Excel из программы ученика |
| 5 | обычный ответ | для проверки «одинаковых неверных ответов» |

Скопировать файл `.variant` на флешку.

### 1.4. Что положить на флешку

```
ФЛЕШКА\
  Тестирование\            ← вся папка dist\Тестирование (с _internal и pyodide)
  Программа ученика\
    Тестирование.exe       ← student_app\target\release\student_app.exe под этим именем
    КАК ЗАПУСТИТЬ.txt      ← из student_app (памятка у компьютера ученика)
    ПРОВЕРКА.bat           ← из student_app: запуск на 60 с с журналом diagnostics.txt
  ПЛАН УСТАНОВКИ.txt     ← docs/УСТАНОВКА_ПРОГРАММЫ_УЧЕНИКА.md
  Проверка в школе.variant
  ПЛАН_ПРОВЕРКИ_В_ШКОЛЕ.md ← этот файл (или распечатка)
```

## Этап 2. В школе: компьютер учителя (У)

1. Скопировать папку `Тестирование` с флешки, например в `C:\Тестирование` (не запускать с флешки).
2. Запустить `Тестирование.exe`. Если Windows пишет «Система Windows защитила ваш компьютер» —
   «Подробнее» → «Выполнить в любом случае». **Записать, было ли это окно** (понадобится подпись программы).
3. На главной странице **записать адрес для учеников** (например `http://192.168.1.10:8080`).
4. Если на главной жёлтое предупреждение про брандмауэр — «Открыть доступ ученикам» → «Да».
   Нужны права администратора: если их нет — **записать** и попросить администратора школы.
5. «Варианты» → «Загрузить из LocalShot» → `Проверка в школе.variant`.
6. «Скачать ярлык для учеников» → файл `Тестирование.html` скопировать на флешку.

---

## Этап 3. В школе: компьютеры учеников

Важно: на компьютерах учеников входить **под учётной записью ученика** (без прав администратора), как на уроке.

### У1 — браузер

1. Скопировать `Тестирование.html` на рабочий стол.

### У2 — программа ученика

1. Запустить `Тестирование.exe` с флешки: программа установится сама и положит на рабочий стол ярлык
   **«Тестирование»** (копировать ничего не нужно, адрес учителя программа найдёт сама).
2. Проверить, что есть WebView2: «Параметры» → «Приложения» → в списке **Microsoft Edge WebView2 Runtime**.
   На Windows 11 он есть всегда; на Windows 10 — почти всегда. Если нет — **записать**.

## Этап 4. Проверки

Каждую строку отметить ✅ или ❌ и записать, что увидели. При ошибке — снимок экрана (LocalShot).

### Блок А. Сеть и вход (система учителя пока **выключена**)

| № | Где | Действие | Ожидается |
|---|---|---|---|
| А1 | У1 | открыть `Тестирование.html` | «Подождите…», без ошибки браузера |
| А2 | У2 | ярлык «Тестирование» | весь экран: «🔒 Тестирование. Подождите, учитель скоро начнёт», «Компьютер учителя не найден… Ищем снова» (система выключена); внизу справа «✕ Закрыть программу» |
| А3 | У | запустить систему, запустить тестирование: вариант «Проверка в школе», 20 минут, галочка **«Редактор Python»** | — |
| А4 | У1 | ничего не нажимать | через 2–3 с сама открылась форма входа |
| А5 | У2 | ничего не нажимать | в течение ~10 с программа сама находит компьютер учителя и открывает вход |
| А6 | У1, У2 | войти: «Браузеров Иван», «Программов Пётр» | открылся тест; в мониторинге учителя оба, «в сети»; у Программова **🔒** |

Если А4/А5 не работают — брандмауэр (этап 2.4) или компьютеры в разных сетях. На У1 открыть адрес из 2.3 вручную в браузере.

### Блок Б. Обычный тест (оба ученика)

| № | Действие | Ожидается |
|---|---|---|
| Б1 | ответить на задания 1–3, переходить между заданиями | ответы сохраняются («Все изменения сохранены»); в мониторинге «ответил N из 5» растёт |
| Б2 | У: «Пауза» | у учеников заставка паузы, поля не редактируются; У: «Продолжить» — всё вернулось |
| Б3 | У: «+5 мин» | у учеников таймер прибавил 5 минут |
| Б4 | У1: закрыть браузер, снова открыть ярлык и войти тем же именем | ответы на месте, время продолжает идти |
| Б5 | задание 4: скачать файл | У1: файл скачался и открывается |

### Блок В. Честность в браузере (У1)

| № | Действие | Ожидается в мониторинге / результатах |
|---|---|---|
| В1 | Alt+Tab в другую программу, подождать 10 с, вернуться | в мониторинге «● вне страницы» (жёлтая строка), потом «Уходы: 1 раз · 10 с» |
| В2 | свернуть браузер и развернуть | «Уходы: 2 раза» |
| В3 | открыть новую вкладку и вернуться | «Уходы: 3 раза» |
| В4 | задание 5: У1 и У2 вводят **одинаковый неверный** ответ, и ещё в задании 1 тоже одинаковый неверный | после завершения: блок «⚠ Одинаковые неверные ответы: Браузеров и Программов — 2 задания» |

### Блок Г. Программа ученика (У2) — главное

Выход из программы в любой момент — Ctrl+Alt+Shift+Q (учитель); при зависании — Ctrl+Alt+Del → «Выйти».
После каждой строки посмотреть на мониторинг учителя.

| № | Действие на У2 | Ожидается |
|---|---|---|
| Г1 | клавиша **Win** | меню «Пуск» не открылось (или мелькнуло и закрылось) |
| Г2 | **Alt+Tab** | ничего не переключилось |
| Г3 | **Alt+F4** | программа не закрылась |
| Г4 | **Ctrl+Esc**, **Ctrl+Shift+Esc** | ни «Пуска», ни диспетчера задач |
| Г5 | **Ctrl+Alt+Del** → «Диспетчер задач» | экран сразу возвращается к тесту (тест идёт на своём рабочем столе), у учителя «открывал: рабочий стол Windows» и уход |
| Г6 | **Ctrl+Alt+Del** → «Отмена» | вернулся тест |
| Г7 | задание 4: скачать файл и открыть | Excel (или LibreOffice) **виден поверх теста**, можно работать; вернуться к тесту щелчком — **пока неизвестно, удобно ли**: записать, как получилось |
| Г8 | задание с файлом-ответом (если есть): «Выбрать файл» | окно выбора файла открывается и не закрывается программой |
| Г9 | во время теста — кнопки «✕ Закрыть программу» нет; **Ctrl+Alt+Shift+Q** | программа закрылась (выход для учителя) |
| Г9а | войти снова, ответить; учитель «Завершить тестирование» | у ученика сама открылась оценка, внизу справа «✕ Закрыть программу» — закрывает, экран возвращается на обычный стол |
| Г10 | запустить программу снова и войти тем же именем | ответы на месте; в мониторинге снова 🔒 |
| Г11 | Ctrl+Alt+Del → «Диспетчер задач» → попробовать снять задачу «Тестирование» | снять **не должно получиться**: экран сразу возвращается к тесту. **Записать**, как было |

Если в нём нет строк «клавиша …» при нажатиях Г1–Г4 — перехват клавиш не работает (см. «Если не работает»).

### Блок Г-Python. Python под заданием (У2)

В программе ученика под каждым заданием кнопка «🐍 Решить на Python»; код выполняет **Python, установленный
на компьютере ученика** (не на компьютере учителя). У1 (браузер) — по-прежнему боковая панель.

| № | Действие на У2 | Ожидается |
|---|---|---|
| П1 | задание 1: «🐍 Решить на Python» | открылся редактор, справа от кнопок «Python 3.x». Если «Python не установлен…» — **записать**, есть ли Python на компьютере и как он ставился |
| П2 | `print(2 ** 10)` → «▶ Запустить» (или F5) | вывод `1024`, «Готово за … с» |
| П3 | «Вставить в ответ» | в поле ответа `1024`, ответ сохранился |
| П4 | `print(1 / 0)` | красная ошибка `ZeroDivisionError`, «Завершено с ошибкой» |
| П5 | `a = input()` и `print(int(a) * 2)`, ввести `21` в поле под выводом | `42` |
| П6 | `while True: pass` → «■ Остановить» | «Остановлено» сразу; через 30 с без остановки — «программа работала дольше 30 с» |
| П7 | задание 4 (с файлом): код с `open('…')` из подсказки под редактором | файл читается без ошибки (программа сама скачала его в папку кода) |
| П8 | закрыть программу (Ctrl+Alt+Shift+Q), открыть снова, войти | код в редакторах на месте |
| П9 | во время П6 посмотреть, не появилось ли чёрное окно консоли | окна нет; тест на месте, у учителя **нет** ухода |
| П10 | вид страницы: слева задание, справа редактор; перетащить границу между ними; «1:1» и «По ширине» над заданием | текст задания чёткий, без искажений; граница двигается, после перехода к другому заданию остаётся там же |
| П11 | Ctrl+PageDown / Ctrl+PageUp | следующее / предыдущее задание |

### Блок Д. Завершение и результаты (У)

| № | Действие | Ожидается |
|---|---|---|
| Д1 | У2: «Сдать работу» | у У2 заставка «Работа сдана»; в мониторинге «🔒 сдал» |
| Д2 | У: «Завершить тестирование» | У1 и У2 видят оценку и правильные ответы |
| Д3 | «Результаты» | таблица ученик × задание, столбец «Уходы» (у Браузерова 3 раза), блок одинаковых ответов |
| Д4 | щёлкнуть по ученику | время на каждом задании, уходы, у Программова «пытался открыть …», «🔒 в программе ученика» |
| Д5 | «📥 Excel» | файл открывается, есть столбец «Уходы» |

### Блок Е. Весь класс (если есть время, 10–15 минут)

| № | Действие | Ожидается |
|---|---|---|
| Е1 | на всех компьютерах класса ярлык или программа ученика, новый короткий тест (5 минут) | все вошли; в мониторинге все «в сети» |

## Если не работает

| Что | Что делать на месте |
|---|---|
| Ученики не открывают адрес | жёлтое предупреждение на главной → «Открыть доступ ученикам»; компьютеры в одной сети? Адрес набрать вручную |
| Программа ученика: «Компьютер учителя не найден» | система учителя запущена? компьютеры в одной сети? «Ввести адрес учителя вручную» — адрес с главной страницы учителя |
| Программа ученика не запускается | нет WebView2 (этап 3, У2 п. 3) или её удалил антивирус — **записать название антивируса** |
| Антивирус ругается на программу ученика | ожидаемо: перехват клавиатуры похож на «клавиатурного шпиона». Записать сообщение; для проверки — добавить в исключения |
| Win / Alt+Tab не блокируются (Г1–Г4) | известный риск прототипа: перехват не удалось проверить с настоящей клавиатурой. Записать; уход всё равно виден учителю (Г5) |
| Программа ученика «зависла» и не закрывается | Ctrl+Alt+Shift+Q или Ctrl+Alt+Del → **«Выйти»** (выход из учётной записи). Диспетчер задач не поможет: программа сразу вернёт экран с тестом |
| Excel не виден поверх теста (Г7) | записать; это следующая доработка программы ученика |
| «Python не установлен» (П1), а Python есть | записать, где он стоит (`py -0p` в командной строке ученика); запустить `ПРОВЕРКА.bat` — в `diagnostics.txt` строка `python: …` |
| Python не запускается или виснет (П2) | записать; файл `diagnostics.txt` от `ПРОВЕРКА.bat` (строки `python: запуск …`) |
