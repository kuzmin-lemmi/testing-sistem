# Аудит интерфейса (октябрь 2026)

Проверены все страницы системы — учителя (главная, варианты, просмотр/правка/конструктор варианта, запуск и монитор
тестирования, результаты, результат ученика, настройки, банк задач и импорт) и ученика (вход, тест, «работа сдана»,
результат, ярлык). Методика — скиллы `impeccable` (audit, adapt, mode-operate) и `redesign-skill`.
Отрисовка проверялась в браузере на ширинах **320, 375, 768, 1024, 1440 px** скриптом: горизонтальная прокрутка
страницы и элементы, вылезающие за экран. Встроенный детектор `impeccable detect` не запускался — проверки сделаны
вручную по его чек-листу.

## Исправлено

**P0 — мешало работать**
- На телефоне (уже 600 px) меню было скрыто (`display: none`) — между разделами не перейти.
  Теперь меню — вторая строка с прокруткой, активный раздел сам прокручивается в поле зрения.
- Экзамен на телефоне: таймер и кнопка «Сдать работу / Завершить тест» уезжали за правый край.
  Теперь шапка переносится в 2–3 строки, номера заданий — лента сверху, кнопки «Назад / Сохранить / Далее» помещаются даже на 320 px.

**P1 — серьёзные неудобства / WCAG AA**
- Страница «Результаты» вылезала за экран даже на 1280 px, «Правка варианта» — на всех ширинах, «Монитор»,
  «Результат ученика», «Запустить тестирование», «Просмотр варианта» — на телефоне и планшете.
  Причина одна: ячейки CSS-сеток не сжимались уже содержимого. Общее правило `min-width: 0` для сеток,
  широкие таблицы на узком экране прокручиваются внутри себя.
- Меню на планшете (768 px) не помещалось по ширине.
- Контраст подписей (`--text-muted` #94a3b8) — 2.6:1 при норме 4.5:1: даты, счётчики, подсказки читались плохо.
  Теперь #64748b (4.8:1), второстепенный текст #475569 (7.6:1); то же в шаблонах ученика.
- Кнопки только со значком (🗑, ✕) без подписи для экранного диктора — добавлены `aria-label`.

**P2**
- Видимая рамка фокуса для клавиатуры (`:focus-visible`) на ссылках и кнопках.
- На сенсорном экране кнопки не ниже 40 px, переключатели В1…В4 — не меньше 32×40 px.
- `prefers-reduced-motion`: без «въезда» страницы и прыжков кнопок; таймер в тесте не мигает.
- Табличные цифры (`tabular-nums`) в таблицах — столбцы баллов не «пляшут».

**Страница «Варианты»** переделана целиком (см. коммит): поиск, фильтры, список работ по месяцам, комплект —
одна строка с В1…В4, сетка заданий с ответами, папка с вариантами.

## Не менялось — на ваше решение

- **Фиолетовый градиент шапки** и **эмодзи в кнопках и меню** — скиллы считают это «типовым ИИ-оформлением».
  Замена на спокойную шапку и единый набор значков изменит привычный вид всей системы — делать только по решению учителя.
- **Шрифты Nunito и JetBrains Mono грузятся из Google Fonts.** В школьной сети без интернета система показывает
  стандартный шрифт — работать можно, но вид отличается. Можно положить шрифты в `static/` (≈300 КБ).
- **Цвета прямо в шаблонах** (десятки мест) вместо переменных — мешает сделать тёмную тему. Делать вместе с ней.
- Много стилей `style="…"` внутри шаблонов — переносить в CSS постепенно, при правке страниц.

## Как перепроверить

1. Запустить систему, открыть страницы в браузере, включить в инструментах разработчика ширину 375 / 768.
2. Автотесты: `python -m unittest discover -s tests` (146 тестов).
