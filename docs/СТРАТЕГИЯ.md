# Стратегия продукта

Дата: 21.10.2026. Черновик для обсуждения: всё можно менять.

## Идея

Платная программа для учителя информатики: проводит тестирование в классе на запертых компьютерах учеников,
считает результаты и показывает, что повторять. Варианты раздаются бесплатно на Инфошаге и открываются
в программе одним щелчком.

Формулировка для продаж: **«Репетиция КЕГЭ в классе: как на экзамене»**. ЕГЭ по информатике сдают
на компьютере, ученикам нужна тренировка в похожих условиях: запертый экран, файлы к заданиям, баллы ЕГЭ.

## Главные решения

### 1. Не переписывать всё сразу

Сервер учителя уже работает (160 автоматических тестов, мониторинг, результаты, Excel, импорт из LocalShot).
Полное переписывание — месяцы без новых возможностей и возврат уже исправленных ошибок.
Учителя платят не за язык программирования, а за то, что программа экономит им время.

Порядок:

1. **Программа ученика на Rust** — новое: запирает экран и открывает внутри себя готовую страницу теста.
   Прототип: [`student_app/`](../student_app/) — на тех же библиотеках, что Tauri (`tao` + `wry`, WebView2),
   но без самого Tauri; около 1 МБ, установка не нужна.
2. **Программа учителя** — нынешний сервер, собранный в EXE, плюс нормальный установщик.
3. Сервер на Rust — постепенно и только если появится настоящая причина (скорость, Linux, защита кода).

### 2. «Уйти незаметно нельзя», а не «уйти нельзя»

Что может программа на компьютере ученика:

| Что | Программа ученика | Браузер (сейчас) |
|---|---|---|
| Окно на весь экран поверх всех, без рамки | да | Esc выходит |
| Перехват Alt+Tab, Win, Alt+F4, Ctrl+Esc | да (низкоуровневый перехват клавиатуры) | нет |
| Заметить диспетчер задач и другие программы | да, сразу сообщить учителю | нет |
| Второй монитор, удалённый доступ, виртуальная машина | можно обнаружить | нет |
| Ctrl+Alt+Del | **нет**, Windows его не отдаёт ни одной программе | нет |
| Выключить кнопкой, выдернуть кабель | нет | нет |

Всё, что нельзя запретить, программа замечает, и учитель сразу видит это в мониторинге.

Важная поправка для КЕГЭ: запереть **всё** нельзя — для заданий с файлами нужны Excel и Python. Поэтому у программы
**список разрешённых программ**, а на любую другую она возвращает окно теста и сообщает учителю.

В школе у учеников должны быть учётные записи **без прав администратора**: окна, запущенные с правами администратора
(например, диспетчер задач у администратора), Windows не даёт убрать обычной программе.
Полная блокировка — только режим киоска Windows (Assigned Access), его настраивает администратор школы;
можно предложить как «строгий режим» с инструкцией.

### 3. Linux

Российские школы переходят на Astra Linux и РЕД ОС. Rust и Tauri собираются под Linux — это плюс.
Проверить у знакомых учителей, что стоит в их классах, до того как вкладываться в Windows-особенности.

## Кто покупает

| Покупатель | Как платит | Что нужно |
|---|---|---|
| Учитель за свои деньги | картой, быстро, небольшие суммы | простая оплата, ключ на почту |
| Школа | договор, счёт, закупка; медленно, больше сумма | ИП/ООО, закрывающие документы; возможно, реестр российского ПО (проверить) |
| Репетиторы, онлайн-школы ЕГЭ | охотнее всего | режим «ученик дома»: сервер в интернете, персональные данные (152-ФЗ) |

Начинаем с учителей и школ: продукт уже под них, а локальная работа — преимущество: данные учеников не покидают школу.

## Лицензия

- **Бесплатный уровень** вместо пробного периода: например, один класс и без запирания экрана.
  Платно: запирание, история учеников, аналитика, Excel. Учителя советуют друг другу то, чем уже пользуются.
- **Ключ проверяется без интернета**: подписанный файл лицензии на имя учителя / школы (подпись Ed25519,
  открытый ключ в программе). Школьная сеть часто без интернета.
- **Без привязки к «железу»**: компьютеры в школе меняют, каждая блокировка — злой учитель и обращение в поддержку.
  С пиратством бороться доступной ценой, а не защитой.

## Варианты на Инфошаге

- Вариант открывается в программе одним щелчком: «скачал → открыл → провёл урок». Это и есть путь к лицензии.
- Файл `.variant` сейчас хранит ответы открыто. Для раздачи — подписывать и шифровать ответы,
  чтобы ученик не открыл файл и не увидел их.
- **Права на задания проверить до продаж.** Банк вариантов собирается из заданий kompege.ru.
  Раздавать для своих уроков — одно, использовать как приманку для платной программы — коммерческое
  использование чужих заданий. Узнать условия kompege.ru и при необходимости договориться с авторами;
  для бесплатной раздачи опираться на открытый банк ФИПИ и собственные задания.

## Что добавить в продукт

1. **Тренажёр КЕГЭ**: интерфейс, похожий на экзаменационный, файлы к заданиям, перевод первичных баллов в тестовые.
2. **История ученика, работа над ошибками, слабые темы класса** — пункты 1–5 из [УЛУЧШЕНИЯ.md](УЛУЧШЕНИЯ.md).
   За это платят: экономит учителю часы.
3. **Автопроверка заданий с кодом (№ 24–27)**: ученик сдаёт программу, система прогоняет её на тестах.
4. **Отчёт для администрации и родителей одной кнопкой**: динамика класса, прогноз баллов.

## Конкуренты

- **Safe Exam Browser** — бесплатная «запиралка» с открытым кодом.
- **kompege, «Решу ЕГЭ», Яндекс Учебник** — бесплатные задания и проверка.

Отличие — связка в одной программе: **вариант → запертый урок в классе → аналитика → работа над ошибками**,
а не одно запирание экрана.

## Проверить (юридически)

- Условия использования заданий kompege.ru в коммерческом продукте.
- Форма продаж: самозанятость / ИП / ООО; что нужно школе для оплаты.
- Нужен ли реестр российского ПО для закупок школами.
- Персональные данные учеников (152-ФЗ): что меняется, если появится режим «ученик дома» с сервером в интернете.
