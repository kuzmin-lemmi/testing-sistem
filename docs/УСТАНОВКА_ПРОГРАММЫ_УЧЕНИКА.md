# Установка в школе: программа ученика и обновление системы учителя

Комплект на флешке:

```
Тестирование\            ← система учителя (новая версия: раскладка программы ученика)
Программа ученика\
  Тестирование.exe       ← программа ученика
  КАК ЗАПУСТИТЬ.txt      ← памятка у компьютера ученика
  ПРОВЕРКА.bat           ← запуск на 60 с с журналом, если что-то не так
Проверка в школе.variant ← пробный вариант
ПЛАН_ПРОВЕРКИ_В_ШКОЛЕ.md
ПЛАН УСТАНОВКИ.txt       ← этот файл
```

Новый вид страницы теста (задание и Python рядом) приходит **с системы учителя**: без её обновления
программа ученика покажет страницу по-старому. Поэтому сначала шаг 1, потом компьютеры учеников.

## 1. Компьютер учителя: обновить систему (≈ 5 минут)

1. Остановить систему, если запущена: главная страница → «Остановить систему» (или значок у часов → «Остановить систему»).
2. Скопировать папку `Тестирование` с флешки **поверх** прежней (например, `C:\Тестирование`), согласиться
   на замену файлов. Папку `Данные` рядом с `Тестирование.exe` не трогать — в ней база, варианты и результаты;
   в комплекте её нет, поэтому она не перезапишется.
   Если система запускается из исходников (`start.bat`, папка `testing-sistem`): вместо копирования — `git pull`.
3. Запустить `Тестирование.exe`. Если Windows пишет «Система Windows защитила ваш компьютер» —
   «Подробнее» → «Выполнить в любом случае».
4. Проверить, что на главной адрес для учеников и нет жёлтого предупреждения про брандмауэр
   (если есть — «Открыть доступ ученикам» → «Да», нужны права администратора).

## 2. Компьютер ученика: что должно быть (проверить один раз)

| Что | Как проверить | Если нет |
|---|---|---|
| Windows 10 или 11 | — | программа не работает на Windows 7/8 |
| WebView2 | «Параметры» → «Приложения» → **Microsoft Edge WebView2 Runtime** | на Windows 11 есть всегда; на 10 — поставить с сайта Microsoft (нужны права администратора) |
| Python 3 (для редактора Python) | Пуск → «cmd» → `py --version` или `python --version` — ответ `Python 3.x` | поставить с python.org; галочки «Add python.exe to PATH» и «py launcher». Без Python тест работает, но «Запустить» пишет «Python не установлен» |
| Одна сеть с учителем | — | программа не найдёт учителя; адрес можно ввести вручную |

## 3. Компьютер ученика: установить программу (≈ 1 минута на компьютер)

Войти **под учётной записью ученика** (как на уроке). Права администратора не нужны.

1. Если на компьютере уже стоит программа ученика и она открыта — закрыть её: кнопка «✕ Закрыть программу»
   внизу справа или Ctrl+Alt+Shift+Q.
2. Вставить флешку, открыть папку `Программа ученика`, дважды щёлкнуть `Тестирование.exe`.
   «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
3. Программа сама:
   - копируется в `%LOCALAPPDATA%\Programs\Тестирование` (старая версия заменяется);
   - кладёт на рабочий стол ярлык **«Тестирование»**;
   - открывается на весь экран: «Подождите, учитель скоро начнёт» и ищет компьютер учителя.
4. Флешку можно вынимать. Дальше ученик открывает программу ярлыком «Тестирование».
5. Закрыть программу до начала теста — «✕ Закрыть программу» внизу справа.

На каждом следующем компьютере — шаги 1–5. Под каждой учётной записью ученика программа ставится отдельно
(она лежит в профиле пользователя).

## 4. Проверка на одном компьютере ученика (≈ 5 минут)

1. Учитель: «Варианты» → «Загрузить из LocalShot» → `Проверка в школе.variant`; запустить тестирование,
   галочка **«Редактор Python»**.
2. Ученик: ярлык «Тестирование» → программа сама нашла учителя → вход.
3. Должно быть видно:
   - вверху тонкая полоса: имя, номера заданий 1–5, таймер, «Сдать работу»;
   - слева задание, справа редактор Python (сразу открыт), внизу слева поля ответа и «← Назад / Далее →»;
   - граница между заданием и редактором перетаскивается мышью; над заданием «− / + / По ширине / 1:1»;
   - `print(2 ** 10)` → «▶ Запустить» → вывод `1024` под редактором; «Вставить в ответ» → `1024` в поле ответа.
4. Учитель в мониторинге видит ученика с 🔒.

Подробная проверка — `ПЛАН_ПРОВЕРКИ_В_ШКОЛЕ.md` (блоки А–Е и П).

## Если не работает

| Что | Что делать |
|---|---|
| Страница теста старого вида (большая плашка «Задание 1 из 5», кнопка «Решить на Python») | на компьютере учителя старая система — шаг 1 |
| «Компьютер учителя не найден» | система учителя запущена? одна сеть? «Ввести адрес учителя вручную» — адрес с главной страницы учителя |
| «Python не установлен…» | шаг 2, строка Python; потом закрыть и снова открыть программу |
| Программа не запускается | нет WebView2 или её удалил антивирус — записать название антивируса |
| Программа зависла | Ctrl+Alt+Shift+Q; если не помогает — Ctrl+Alt+Del → «Выйти» |
| Нужно понять, что происходит | `ПРОВЕРКА.bat` из папки `Программа ученика` (программа на 60 с), файл `diagnostics.txt` — привезти |
