# Участие в проекте

[← На главную](README.md) · [Устройство проекта](CLAUDE.md) · [Список улучшений](docs/УЛУЧШЕНИЯ.md)

Интерфейс, документацию, комментарии и сообщения коммитов пишем по-русски.

## Окружение разработки

Клонируйте репозиторий и установите основные зависимости по [быстрому старту](README.md#быстрый-старт), затем выполните в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
$env:EGE_DATA_DIR = Join-Path $PWD "data-dev"
.\.venv\Scripts\python.exe server.py
```

Сервер откроется по адресу `http://127.0.0.1:8080`. Переменная `EGE_DATA_DIR` направляет данные разработки в отдельную папку. Она действует в текущем сеансе PowerShell.

## Проверки перед pull request

Из корня репозитория:

```powershell
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты создают собственные временные папки данных. CI проверяет Python 3.8 и 3.12 на Windows, а также запускает Ruff.

Если меняется программа ученика, проверки выполняются на Windows из папки `student_app`:

```powershell
cargo test
cargo clippy --all-targets
cargo build --release
```

Для сборки нужны Rust с набором `x86_64-pc-windows-msvc` и Visual Studio Build Tools. Подробности — в [README программы ученика](student_app/README.md#сборка).

## Как подготовить изменение

1. Создайте отдельную ветку с понятным названием.
2. Для новой возможности добавьте автоматическую проверку в `tests/` по примеру соседних тестов.
3. При изменении базы добавьте миграцию в `migrate_db`: существующая база учителя должна продолжать открываться.
4. Если меняется интерфейс, проверьте страницы в браузере. Программу ученика проверяйте на Windows.
5. Обновите затронутую инструкцию и статус задачи в соответствующем плане.
6. В pull request опишите проблему, результат и выполненные проверки. Для изменений интерфейса приложите изображение с вымышленными данными.

Для правок документации проверьте ссылки, команды и читаемость страницы на GitHub.

## Что прикладывать к сообщению об ошибке

Укажите версию Windows и Python, способ запуска, последовательность действий и ожидаемый результат. Для программы ученика уточните, используется ли отдельный рабочий стол.

Перед публикацией снимков экрана и журналов уберите имена учеников, ответы, адреса школьной сети и другие личные данные. Папки `data/`, `Данные/`, рабочие базы и файлы учеников в репозиторий не добавляем.
