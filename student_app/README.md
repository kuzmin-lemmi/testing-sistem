# Программа ученика (прототип)

Окно теста на весь экран, из которого **незаметно не уйти**. Открывает обычную страницу теста с компьютера учителя,
поэтому всё, что умеет страница ученика (задания, черновик, Python, загрузка файлов), работает без изменений.
Зачем это нужно и куда развивать — [docs/СТРАТЕГИЯ.md](../docs/СТРАТЕГИЯ.md).

Написана на Rust на тех же библиотеках, что и Tauri (`tao` — окно, `wry` — встроенный браузер WebView2),
но без самого Tauri: для «запертой оболочки» вокруг одной страницы его настройки не нужны.
WebView2 уже есть в Windows 10/11. Готовая программа — около 1 МБ, со значком; в комплекте она называется `Тестирование.exe`.

## Что делает

| | |
|---|---|
| **Свой рабочий стол** | тест идёт на отдельном рабочем столе Windows, как в Safe Exam Browser: там нет проводника, панели задач и меню «Пуск» — Win и Alt+Tab увести некуда. Ушёл на обычный стол (Ctrl+Alt+Del → «Диспетчер задач») — стол теста возвращается сразу, учитель видит «открывал: рабочий стол Windows». После выхода экран возвращается на обычный стол. `--no-desktop` — без своего стола |
| Окно | на весь экран, без рамки, поверх всех окон; закрыть нельзя |
| Адрес | только страницы системы тестирования: другие сайты и новые окна не открываются |
| Ожидание | пока система учителя не запущена — «Подождите, учитель скоро начнёт», потом сама открывает вход |
| Чужая программа впереди | окно теста возвращается (раз в 0,3 с), учитель видит «открывал: …» и уход в мониторинге |
| Меню «Пуск», поиск | закрываются (Esc) и тоже показываются учителю |
| Окно с правами администратора (диспетчер задач) | убрать нельзя — Windows не даёт, — но тест остаётся поверх него, учитель видит уход |
| Python под заданием | редактор на странице теста присылает код, программа выполняет его **Python ученика** (лаунчер `py`, реестр, `PATH`; заглушка Microsoft Store пропускается). Папка `%LOCALAPPDATA%\Тестирование\python\<задание>` с файлом задания под настоящим именем, 30 с и 1 ГБ памяти на запуск, «Остановить» убивает и запущенные программой процессы (Job Object). Нет Python — ученик видит «Python не установлен» |
| LibreOffice для файла задания | над заданием с файлом `.xlsx`, `.ods`, `.csv`, `.txt` кнопка «📊 Открыть в LibreOffice Calc» (вместо «Скачать»: на столе теста скачанный файл открыть нечем). Файл — в `%LOCALAPPDATA%\Тестирование\office\ученик N\<задание>` (уже есть — работа ученика, не трогается; у каждого ученика своя папка, папки прежних удаляются — на школьных компьютерах одна учётная запись на всех). Свой профиль LibreOffice (иначе файл уйдёт в LibreOffice на обычном столе), окно документа — под шапкой теста, в шапке вкладки «📄 Тест · 📊 Числа.xlsx». Диалоги («Импорт текста» для .csv) — вперёд. Закрывается с тестом и программой (Job Object). Работа в LibreOffice — не уход. Нет LibreOffice — Excel, нет и его — «Скачать» |
| Разрешённые программы | Excel, Word, LibreOffice, Python (IDLE), Блокнот, Калькулятор — для заданий с файлами; на это время тест перестаёт быть поверх всех |
| Клавиши | перехват Win, Alt+Tab, Alt+Esc, Alt+F4, Ctrl+Esc, Ctrl+Shift+Esc — запасной путь: на настоящем компьютере ученика нажатия до перехвата **не доходили** (см. «Проверено») |
| Выход ученика | кнопка **«✕ Закрыть программу»** внизу справа — **только вне теста**: на ожидании, на входе, на «Тестирование не запущено» и на странице с оценкой (учитель завершил тестирование). Вошёл в тест — закрыть нельзя, пока не откроется оценка; «Назад» (Alt+←) не помогает: программа помнит, что ученик в тесте |
| Выход для учителя | **Ctrl+Alt+Shift+Q** — всегда; ловит сама страница и передаёт программе (не перехват клавиатуры) |
| Учитель видит | в мониторинге у ученика 🔒 — он в программе, а не в обычном браузере |

Ctrl+Alt+Del Windows не отдаёт ни одной программе. Уход через него (диспетчер задач, смена пользователя) учитель видит.

## Запуск

**Установка.** Первый запуск (с флешки, из любой папки) копирует программу в профиль ученика
`%LOCALAPPDATA%\Programs\Тестирование\Тестирование.exe` и кладёт на рабочий стол ярлык **«Тестирование»** со значком.
Права администратора не нужны; новая версия, запущенная так же, заменяет старую. Не устанавливается: отладочная
сборка, `--portable`, `--server`.

**Подключение к учителю — само.** Программа обходит свои локальные сети (порт 8080, адрес `/test/hello`; старая
версия системы — по `/test/alive`) и:

- нашла одну систему — подключается и запоминает адрес (`%LOCALAPPDATA%\Тестирование\server.txt`);
- несколько — ученик выбирает (кнопки с именем компьютера учителя);
- ни одной — ищет снова каждые 5 с; можно «Ввести адрес учителя вручную».

Запомненный адрес не отвечает (учитель сменил адрес) — ищет заново. Поиск — несколько секунд (до ~760 адресов).

Для проверки адрес можно задать явно — тогда не ищет и не запоминает: `--server 192.168.0.77` или файл `server.txt`
рядом с программой.

Список разрешённых программ можно заменить файлом `allowed.txt` рядом с программой: по одному имени файла программы
в строке (`excel.exe`), строки с `#` — комментарии.

Для проверки на своём компьютере: `--exit-after 30` — программа сама закроется через 30 секунд и вернёт экран.
Диагностика: переменная окружения `STUDENT_APP_DEBUG=1` — программа пишет, какие клавиши видит и какие окна возвращает.

**`КАК ЗАПУСТИТЬ.txt`** — памятка для компьютера ученика по шагам.
Для разработки: **`ПРОВЕРКА.bat`** — запуск `student_app.exe` на 60 секунд с диагностикой в `diagnostics.txt`;
образец адреса — `server.txt.example`. Порядок проверки в школе — [docs/ПЛАН_ПРОВЕРКИ_В_ШКОЛЕ.md](../docs/ПЛАН_ПРОВЕРКИ_В_ШКОЛЕ.md).

## Сборка

Нужны Rust (`rustup`, набор `x86_64-pc-windows-msvc`) и Visual Studio Build Tools.

```
cargo build --release
```

Готовая программа — `target\release\student_app.exe` (без чёрного окна консоли, со значком из `assets\icon.ico`,
его рисует `assets\make_icon.py`). В комплект кладётся под именем `Тестирование.exe`.

## Проверено на компьютере ученика (22.10.2026, Windows 10, школьная сеть)

Версия **без своего стола** (перехват клавиатуры + возврат окна):

- Связь, ожидание, вход, 🔒 у учителя, ответы, «Сдать работу» — работают.
- **Win, Alt+Tab, Ctrl+Esc и Ctrl+Alt+Del → «Диспетчер задач» увели с теста** — перехват клавиатуры нажатий не получил
  (Alt+F4 окно не закрыл: закрытие окна программа запрещает). Каждый уход учитель увидел: «11 раз · 14 с»,
  «открывал: searchapp.exe / проводник / диспетчер задач»; тест возвращался примерно за секунду.
- Меню «Пуск» Windows 10 — процесс `SearchApp.exe` (в Windows 11 — `SearchHost.exe`): добавлен в список.

Поэтому сделан **свой рабочий стол**. На компьютере ученика его ещё не проверяли.

## Что не проверено

- **Свой рабочий стол на компьютере ученика**: Win, Alt+Tab, Ctrl+Esc, Ctrl+Alt+Del → «Диспетчер задач»,
  Ctrl+Alt+Shift+Q.
- **Файлы к заданиям на своём столе**: откроется ли Excel/LibreOffice на столе теста или уйдёт на обычный стол
  (тогда ученик его не увидит — нужно открывать файлы из самой программы). Если мешает — `--no-desktop`.
- Учётная запись ученика без прав администратора.
- Второй монитор (окно сейчас только на основном), удалённый доступ, виртуальная машина.
- Загрузка и открытие файлов к заданиям в разрешённой программе (Excel поверх теста).
- Python под заданием на своём рабочем столе и на компьютере ученика без прав администратора; компьютер без Python.

## Устройство

- `src/main.rs` — окно, встроенный браузер, события, сообщение серверу об уходе (`POST /test/away` с `app`).
- `src/desktop.rs` — свой рабочий стол: создать, запустить на нём копию программы (`--on-desk`), вернуть экран.
- `src/lock.rs` — возврат стола теста, перехват клавиатуры (в своём потоке, переставляется каждые 2 с: Windows молча снимает перехват,
  если он хоть раз ответил медленно) и слежка за окном на переднем плане.
- `src/server.rs` — адрес учителя, разрешённые программы, ожидание запуска системы, скачивание файла задания.
- `src/python.rs` — Python ученика: поиск, запуск в Job Object, вывод странице, ввод, остановка.
- `src/office.rs` — LibreOffice (или Excel) для файла задания: поиск, свой профиль, Job Object, окна документов под шапкой и вкладки.
- `src/json.rs` — разбор сообщений страницы и строки для скриптов в ней.

Сервер узнаёт программу по `TestingStudentApp/0.1` в User-Agent (`blueprints/student.py`, `_from_student_app`).
