ПРОГРАММА УЧЕНИКА «ТЕСТИРОВАНИЕ»

УСТАНОВКА (один раз на каждый компьютер ученика, под учётной записью ученика)
1. Запустите Тестирование.exe с флешки (двойной щелчок).
   Если Windows пишет «Система Windows защитила ваш компьютер» —
   «Подробнее» → «Выполнить в любом случае».
2. Программа сама установится и положит на рабочий стол ярлык «Тестирование».
   Флешку можно вынимать: больше ничего копировать не нужно.
   (Программа лежит в профиле ученика: %LOCALAPPDATA%\Programs\Тестирование;
   права администратора не нужны. Новая версия ставится так же — поверх старой.)

ПОДКЛЮЧЕНИЕ К УЧИТЕЛЮ — само
• Программа сама ищет в сети компьютер с системой тестирования и запоминает его.
• Нашлось несколько — ученик выбирает свой (видно имя компьютера учителя).
• Не нашлось — проверьте, что система учителя запущена; можно нажать
  «Ввести адрес учителя вручную» и ввести адрес с главной страницы учителя
  (например 192.168.0.77).
• Если адрес учителя поменялся — программа найдёт его заново сама.

ЗАКРЫТЬ ПРОГРАММУ (ученик): кнопка «✕ Закрыть программу» внизу справа.
   Во время теста её нет — она появится на странице с оценкой, когда учитель
   завершит тестирование (для всех или только этому ученику).
ВЫХОД ДЛЯ УЧИТЕЛЯ — в любой момент: Ctrl + Alt + Shift + Q
Если программа зависла: Ctrl + Alt + Del → «Выйти» (выход из учётной записи).
Диспетчер задач НЕ поможет: программа сразу вернёт экран с тестом.

Программа открывает тест на ОТДЕЛЬНОМ рабочем столе Windows: там нет панели задач
и меню «Пуск». После выхода экран сам возвращается на обычный рабочий стол.

ФАЙЛ ЗАДАНИЯ В LIBREOFFICE
• Над заданием с файлом (.xlsx, .ods, .csv, .txt) — кнопка «📊 Открыть в LibreOffice Calc».
  Документ открывается поверх теста, под верхней полосой; вверху вкладки «📄 Тест» и файл —
  ими переключаться. Работа в LibreOffice уходом не считается.
• Нужен LibreOffice (libreoffice.org) или Excel. Нет ни того, ни другого — остаётся «Скачать».
• Когда учитель завершит тестирование, LibreOffice закроется сам.

PYTHON ПОД ЗАДАНИЕМ (если учитель включил «Редактор Python»)
• Под заданием кнопка «🐍 Решить на Python»: редактор, «▶ Запустить» (F5),
  «■ Остановить», «Вставить в ответ». Код выполняет Python ЭТОГО компьютера —
  он должен быть установлен (python.org). Нет — ученик видит «Python не установлен».
• Файл задания программа сама кладёт рядом с кодом: open('17.txt') работает.
• Программа работает не дольше 30 секунд и не больше 1 ГБ памяти.

Что попробовать во время теста (и смотреть мониторинг у учителя):
  • Win, Alt+Tab, Alt+F4, Ctrl+Esc       — ничего не открывается, тест на месте
  • Ctrl+Alt+Del → Диспетчер задач        — экран сразу возвращается к тесту,
                                            у учителя «открывал: рабочий стол Windows»
  • задание с файлом: «Открыть в LibreOffice Calc» — документ под шапкой теста,
                                            вкладки «Тест» и файл вверху переключаются
  • у учителя в мониторинге рядом с именем 🔒
