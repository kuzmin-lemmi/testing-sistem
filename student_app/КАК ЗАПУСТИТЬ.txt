ПРОГРАММА УЧЕНИКА — ПРОБНЫЙ ЗАПУСК

0. Рядом с программой должен лежать server.txt с адресом компьютера учителя —
   тот, что на главной странице системы учителя, без /test в конце, например:
       http://192.168.0.77:8080
   (образец — server.txt.example: переименуйте в server.txt и исправьте Блокнотом)

1. Скопируйте всю папку с программой на рабочий стол компьютера ученика.

2. Проверка сети: откройте Edge и наберите адрес учителя с /test в конце
   (например  http://192.168.0.77:8080/test). Должна открыться страница входа
   или «Тестирование не запущено».
   Если «Не удаётся получить доступ к сайту» — на компьютере учителя нажмите
   «Открыть доступ ученикам» на главной странице; проверьте, что оба компьютера
   в одной сети (начало адресов одинаковое, например 192.168.0.).
   Закройте Edge.

3. Первый запуск — двойной щелчок по ПРОВЕРКА.bat.
   Программа откроется на весь экран и САМА ЗАКРОЕТСЯ через 60 секунд.
   Если Windows пишет «Система Windows защитила ваш компьютер» —
   «Подробнее» → «Выполнить в любом случае».

4. Когда всё работает — запускайте student_app.exe (без ограничения по времени).

ЗАКРЫТЬ ПРОГРАММУ (ученик): кнопка «✕ Закрыть программу» внизу справа.
   Во время теста её нет — она появится на странице с оценкой, когда учитель завершит тестирование.
ВЫХОД ДЛЯ УЧИТЕЛЯ — в любой момент: Ctrl + Alt + Shift + Q
Если программа зависла и не закрывается: Ctrl + Alt + Del → «Выйти» (выход из учётной записи).
Диспетчер задач НЕ поможет: программа сразу вернёт экран с тестом.
ПРОВЕРКА.bat закрывает программу сама через 60 секунд — для первых проб удобнее она.

Программа открывает тест на ОТДЕЛЬНОМ рабочем столе Windows: там нет панели задач и меню «Пуск».
После выхода экран сам возвращается на обычный рабочий стол.

Что попробовать во время теста (и смотреть мониторинг у учителя):
  • Win, Alt+Tab, Alt+F4, Ctrl+Esc       — ничего не открывается, тест на месте
  • Ctrl+Alt+Del → Диспетчер задач        — экран сразу возвращается к тесту,
                                            у учителя «открывал: рабочий стол Windows»
  • задание с файлом: скачать и открыть   — записать, открылся ли Excel ПОВЕРХ теста
  • у учителя в мониторинге рядом с именем 🔒

После ПРОВЕРКА.bat рядом появится diagnostics.txt — его стоит принести обратно.
