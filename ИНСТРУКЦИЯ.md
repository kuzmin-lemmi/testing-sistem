# Система тестирования — инструкция для учителя

Одна страница. Всё, что нужно, чтобы провести тест в кабинете информатики.

## 1. Установка (один раз)

**Вариант А — готовая программа** (если вам дали папку «Тестирование» с `Тестирование.exe`):
скопируйте папку на компьютер учителя и запустите `Тестирование.exe`. Ничего устанавливать не нужно.

**Вариант Б — из исходников:** нужен Python 3.8+ (python.org, при установке отметьте «Add Python to PATH»).
Запустите `УСТАНОВКА.bat` — он поставит компоненты и создаст ярлык «Тестирование ЕГЭ» на рабочем столе.

## 2. Запуск

Откройте ярлык. Чёрного окна нет: система работает в фоне, у часов появляется значок, а в браузере
открывается **главная страница**. Если закрыть браузер, система продолжает работать — откройте ярлык снова.

На главной странице вы видите:
- **адрес для учеников** — крупно, один; рядом кнопка «Копировать»;
- **«Что происходит в системе»** — понятные записи: какой компьютер подключился, кто вошёл в тест, ошибки;
- кнопки **«Скачать ярлык для учеников»**, **«Остановить систему»** и **«Скачать журнал для разработчика»**.

### Первый запуск: брандмауэр Windows
Если ученики не могут подключиться, на главной странице будет жёлтое предупреждение. Нажмите
**«Открыть доступ ученикам»** и ответьте «Да» в окне Windows. Делать это нужно один раз на компьютер учителя.

## 3. Компьютеры учеников (один раз)

Нажмите «Скачать ярлык для учеников» и скопируйте файл `Тестирование.html` на рабочие столы учеников.
Ученик открывает ярлык и ждёт: когда вы запустите тест, сама откроется форма входа.
Можно и без ярлыка: ученик вводит адрес с главной страницы в браузере.

## 4. Как провести тест

1. **Подготовьте вариант.** В LocalShot сохраните скриншоты заданий в вариант (файл `.variant`).
   На главной странице нажмите **«Загрузить из LocalShot»**. Правильные ответы лежат внутри файла — ученикам его не давайте.
2. **Запустите тестирование:** «Запустить тестирование» → выберите вариант → укажите время.
   Галочка **«Задания вразброс»** даёт каждому ученику свой порядок заданий.
3. **Ученики входят** (фамилия и имя). **Время у каждого ученика идёт со своего входа** — опоздавший получает полное время.
4. **Следите** на странице «Мониторинг»: кто в сети, сколько ответил, сколько времени осталось. Можно поставить паузу и продлить время.
5. **Завершите тестирование.** Каждый ученик сразу видит свою оценку и правильные ответы, вы — таблицу результатов.
   После завершения автоматически создаётся резервная копия базы.
6. **Результаты:** раздел «Результаты» — оценки, ответы каждого ученика, выгрузка таблицы для журнала.

## 5. Если что-то не так

| Проблема | Что делать |
|----------|-----------|
| Ученик не может открыть страницу | На главной странице: нет ли жёлтого предупреждения про брандмауэр? Компьютеры в одной сети (Wi-Fi/кабель)? Попробуйте адреса в «Если адрес не открывается». |
| Ученик закрыл браузер | Пусть войдёт снова с теми же фамилией и именем. Время продолжает идти. |
| Ученик вошёл с другого компьютера | Сообщение «уже решает тест на другом компьютере» — подождите 30 секунд после закрытия старого окна. |
| Адрес изменился | Откройте главную страницу — там всегда актуальный адрес. Если используете ярлык ученика, скачайте его заново. |
| Система не запустилась | Откройте файл `Данные\logs\server.log` и отправьте его разработчику (или кнопка «Скачать журнал»). |
| Случайно закрыли систему | Откройте ярлык снова — данные сохранены. |

## 6. Данные и обновление

- Все данные (ученики, ответы, варианты) лежат в папке **`Данные`** (у готовой программы — рядом с `Тестирование.exe`, при установке из исходников — `data`).
- **Резервные копии** — в `Данные\backups`: при каждом запуске системы и после каждого завершённого теста (хранятся последние 20).
- **Обновление:** замените файлы программы новой версией, **папку `Данные` не удаляйте**. Всё останется на месте.
- Перенос на другой компьютер: скопируйте папку `Данные`.
